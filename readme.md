# OnlyClick Frontend - React.js


## Features
✅ **User Authentication** (Login with API)  
✅ **Protected Routes** (Dashboard access only for logged-in users)  
✅ **JWT Token Handling** (Stored in sessionStorage)  
✅ **Context API** (Global State Management)  
✅ **API Integration** (Axios used for API calls)  
✅ **User Data Storage** (Session Persistence)  
✅ **Logout Functionality** (Clears session & redirects)  

---

## 🔧 Tech Stack
- **React.js** (Frontend Framework)  
- **React Router** (For Navigation)  
- **Axios** (For API Requests)  
- **Context API** (State Management)  
- **Session Storage** (Authentication Handling)  
- **TailWind CSS** (For Styling)  

---

## 📌 Setup & Installation
### 1️. Clone the Repository  
```sh
git clone https://github.com/Sushanth1425/onlyclick-recuritment.git
cd onlyclick-recuritment
```

### 2. Install Dependencies  
```sh
npm install
```

### 3. Start the App  
```sh
npm start
```
This will start the React app at **`http://localhost:3000/`**.
